01

Prepare Node and model access

Use Node.js 24 or later and a funded model API account. On Windows the SDK may require Git Bash. The HTTP docs server needs internet access. The official filesystem server is pinned and installed with this app.

node --version
npm --version
02

Install and create your .env file

From presentations run these commands. Preserve an existing .env, enter the API key privately and restart after changes. Existing shell values take precedence.

cd .\agent-sdk\lesson24-external-mcp
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the web application

Keep this terminal running. The Agent SDK launches the external filesystem process when needed; you do not start it manually. Ctrl+C stops the web application.

npm start
# http://127.0.0.1:3124
04

Search the real docs and list a classroom folder

Run the HTTP and stdio experiments. Inspect actual fully qualified tool names, connection status and returned sources or filenames. The allowed root is a fresh classroom folder, not your entire computer.

npm run sample:env -- docs-http
npm run sample:env -- stdio-code
05

Load project config and combine transports

Project mode writes and loads an actual .mcp.json with project settings enabled. Combined mode connects both real servers in one session. No manual config edit is required for the classroom exercise.

npm run sample:env -- stdio-config
npm run sample:env -- combined
06

Compare approval and connection timing

Exact approval allows directory listing but denies an unapproved second tool. acceptEdits has no MCP pre-approval. Startup mode labels a two-second wrapper delay and reports actual elapsed initialization time.

npm run sample:env -- exact-approval
npm run sample:env -- accept-edits
npm run sample:env -- startup-wait
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3124
# Optional on Windows: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Keep the actual key private. No Managed Agents agent ID or environment ID is required. No duplicate snapshot is included.

Troubleshooting

Use the URL printed by startup. If another app occupies the port, change PORT and restart. If API credit is unavailable, add credit to the account used by this key. MCP connection failures remain visible; no saved response replaces a failed live call. The CLI experiments use the same local key and pinned server dependencies.
