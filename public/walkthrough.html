01

Read the UML as alternative paths

The diagram groups setup and alternative experiments. Code declarations, project config and the permission comparisons are not all executed by every query. Follow the selected mode and its trace.

02

Installed server instead of startup downloads

The app uses pinned @modelcontextprotocol/server-filesystem and invokes its installed entry point with Node. This avoids downloading an unpinned package at every run and handles Windows paths as separate arguments.

03

Connection timing is version-dependent

The presentation summarizes connection waits. Current runtime behavior also depends on named servers, tool-search deferral and cached discovery. This app explicitly sets a 6000 ms first-turn wait and alwaysLoad, preserves init status and polls actual current status. The two-second wrapper delay is a labelled classroom experiment, not a claim about default startup duration.

04

Availability is not approval

The visible namespace does not mean every call can execute. Exact approval and acceptEdits experiments record actual denials. No bypassPermissions mode is used. The docs wildcard in Combined still passes through a separate search-only host guard.

05

Controlled project settings

The generated .mcp.json loads with settingSources: ["project"], enableAllProjectMcpServers and strictMcpConfig: false in that mode only. Other experiments use code-only declarations and strict MCP configuration. These settings do not modify your existing home configuration.

06

Transport references

stdio uses a command and arguments; HTTP uses a URL. Legacy SSE and JSON streamable-http aliases are reference topics here, not live experiments. In-process SDK servers were taught in Lessons 22 and 23; no in-process server substitutes for the external servers in this app.

07

Authentication and cached discovery

OAuth and private remote credentials belong to the next lesson. The public docs endpoint used here needs no remote service credential. Each classroom run uses fresh local runtime directories, so this app does not claim to benchmark warmed discovery caches or demonstrate every timeout default.

08

Read-only classroom behavior

The filesystem process is restricted to its supplied root, and the host allows only directory listing. The docs host guard rejects feedback and other tools. Original fixture bytes are checked after the run. These controls describe this application; they are not an operating-system sandbox.
